# Beads Guidance

This repository describes Beads workflow in `AGENTS.md`, but does not currently check in a
`.beads` state directory. Until Beads is initialized, keep durable Beads guidance in `AGENTS.md`
and this document.

For non-trivial Beads-tracked work, use `$superpowers` before planning and use
`$repo-quality-gate` through final verification. If either skill is unavailable, record the
limitation and approved fallback in the issue notes or closure reason once Beads issue state is
available.
